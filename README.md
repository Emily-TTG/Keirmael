# Keirmael

## Build
The following options are respected by the build process in addition to the
standard Make variables (`CC`, `CFLAGS` etc.):

|Name|Default|Description|
|---|---|---|
|`MAINTAINER`|`unset` |Enables extra build diagnostics/strictness.|
|`TARGET`|`x86_64`|Selects the target architecture. For available architectures see `toolchain/target`.|
